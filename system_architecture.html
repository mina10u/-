💻 学習者端末 (Client) Tauriアプリ本体内に「同梱Python」と「小型ローカルAI推論エンジン」を備え、コーディング・実行・ヒント提示はネット不要のローカル完結[cite: 3]。
🌐 インターネット通信 コード全文は送信せず、ログイン時のアカウント認証および合否・スコア・エラー種別・バッジ獲得情報のみをHTTPS通信で送受信[cite: 3, 5]。
🖥️ Web & AP サーバ APIエンドポイントとして認証処理、データのバリデーション、同期キューの受け入れ、課題配信を担当[cite: 1, 3]。
🗄️ DB サーバ MySQLまたはNoSQL（Firestore等）を用い、学習ログ・スコア・実績バッジを永続化[cite: 1, 3]。
👥 管理・教員クライアント 指導員による学習進捗の可視化や、開発者・管理者による課題マスタ・テストケースのコンテンツ更新を実施[cite: 3, 4]。
