各レイヤーの責務と構成詳細

構成要素 責務・動作詳細 通信プロトコル / 技術
💻 学習者端末 (Client) Tauriアプリ本体内に「同梱Python」と「小型ローカルAI推論エンジン」を備え、コーディング・実行・ヒント提示はネット不要の完全ローカルで動作[cite: 3]。 Tauri IPC / OSプロセス制御 (CWD作業ディレクトリ実行)[cite: 3]
🌐 インターネット通信 コード全文は送信せず、ログイン時のアカウント認証および合否・スコア・エラー種別・バッジ獲得情報のみを送受信[cite: 3]。ネット切断時はローカルキューへ保持[cite: 3]。 HTTPS / TLS 暗号化通信 (REST API, JSON)[cite: 3]
🖥️ クラウド Web & AP サーバ 認証処理、データのバリデーション、オフライン蓄積キューの受け入れ・マージ、課題データの配信を担当[cite: 3]。 Node.js / FastAPI / Firebase Cloud Functions[cite: 3]
🗄️ クラウド DB サーバ ユーザー情報、学習履歴（得点・エラーログ）、実績バッジマスタを永続化保存[cite: 3]。 MySQL / PostgreSQL または Firestore[cite: 3]
👥 管理・教員クライアント 指導員による生徒の学習進捗・つまずき傾向の可視化、開発者による課題マスタやテストケースの登録・更新を実施[cite: 3]。 Webブラウザ (管理コンソール)[cite: 3]
