アクティビティ図

実行・採点・AIフォールバックフロー

課題演習でコードを編集し、保存・実行・テスト・採点・AI支援を行う代表的な流れです。

flowchart TD
    Start([開始]) --> Select[課題を選択]
    Select --> Edit[コードを編集]
    Edit --> AutoSave[端末内へ自動保存]
    AutoSave --> Choice{操作を選択}
    Choice -- 実行 --> Validate[実行要求を検証]
    Validate --> Sandbox[隔離環境でPython実行]
    Sandbox --> Limit{制限超過?}
    Limit -- はい --> Stop[関連プロセスを停止]
    Stop --> ErrorResult[タイムアウト / 実行エラー表示]
    Limit -- いいえ --> Output[標準出力・標準エラー表示]
    ErrorResult --> AskAI
    Output --> Tests{課題演習?}
    Tests -- いいえ --> Choice
    Tests -- はい --> RunTests[テストケースを実行]
    RunTests --> Calc[配点に基づき採点]
    Calc --> AIState{AI評価が必要?}
    AIState -- いいえ --> Result[採点結果を表示]
    AIState -- はい --> AIReady{AI利用可能?}
    AIReady -- はい --> Analyze[エラー・コードを分析]
    AIReady -- いいえ --> Incomplete[AI評価未完了を表示]
    Analyze --> Result
    Incomplete --> Result
    Result --> AskAI[ヒントを確認]
    AskAI --> Fix{コードを修正する?}
    Fix -- はい --> Edit
    Fix -- いいえ --> SaveRecord[学習記録をローカル保存]
    SaveRecord --> Login{ログイン済み・通信可能?}
    Login -- はい --> Sync[クラウドへ同期]
    Login -- いいえ --> Queue[同期待ちキューへ保持]
    Sync --> End([終了 / 次の課題へ])
    Queue --> End
    Choice -- 保存のみ --> AutoSave

    class Choice,Limit,Tests,AIState,AIReady,Fix,Login decision

AIが使えない場合も、コード編集・実行・機械的テスト・ローカル保存は継続します。AI評価を必須とする採点は未完了として扱い、合格にはしません。
