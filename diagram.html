2. アクティビティ図（エラー発生〜解決フロー）

ユーザーがコードを実行し、エラーが発生してからAIと辞書を活用して解決するまでの処理フローです。

(開始) │ ▼ [ ユーザーがコードを記述・編集 ] │ ▼ [ 実行ボタンを押下 ] ── (Python実行エンジンへIPC送信) │ ├─────── (成功) ────► [ コンソールに実行結果を表示 ] ────► (完了) │ ▼ (エラー発生) [ やさしい日本語エラーに変換してコンソール表示 ] │ ▼ [ Rustバックエンドでエラー原因を解析 ] │ ▼ [ AIが年齢設定（こども/大人）に合わせて段階的ヒント生成 ] │ ▼ [ ヒント内に提示された関連関数リンクをクリック ] │ ▼ [ 関数辞書パネルが自動で開き、該当の構文解説・例を表示 ] │ ▼ [ ユーザーがコードを修正して再実行 ] │ ▼ [ エラー解消！ ➔ 成長カルテに記録 ＆ アチーブメント判定 ] │ ▼ (完了)

※ 画像（PNG/SVG）やMermaid.js等での図解表示へ差し替えることも可能です。
