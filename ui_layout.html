各レイアウト領域の仕様と操作

配置ブロック 内包コンポーネント 動作・機能仕様
📌 トップヘッダー ロゴ、対象バッジ、モード切替トグル、大人向け切替 「🎯 課題演習」と「📁 自由創作」のワンクリック切り替え、ふりがな有無（こども／大人）のグローバル状態管理を担当[cite: 3, 7]。
【左上】エディタ領域 お題バナー、ファイルタブ、Monaco Editor、ツールバー 課題のゴール確認、複数ファイル（main.py/helper.py等）の切り替え編集、コード整形・構文挿入に対応[cite: 3, 7]。
【左下】コンソール領域 実行ボタン、テストパターン切替、Diff差分、エラージャンプ ワンクリックでローカルPythonを実行し、目標との差分比較や別ファイルのエラー行へのジャンプリンクを表示[cite: 3, 7]。
【右上】AI支援パネル ロボットアバター、段階的ヒント表示、対話入力欄 答えをすぐ出さず、「注目箇所」→「概念」→「修正方針」とステップアップ式に助言する[cite: 3, 7]。
【右下】辞書パネル 検索ボックス、ふりがな付きカード、既習言語比較 小学生でも読めるルビ付き解説と、JavaやJavaScript等の書き方との対比を即時検索表示[cite: 3, 7]。
