システム要件定義書 (RDD)

プログラミング学習 AI誤り分析アシスタント（CodeLab）

システム種別: Windows デスクトップアプリ
開発フレームワーク: Tauri v2 (Rust + React)
作成日: 2026年10月
開発体制: チーム（6名）

1. プロジェクト概要・背景・目的

1.1 背景

プログラミング初学者（小学生高学年〜大人の未経験者）は、コード記述時の構文エラーや、期待した結果と異なる論理エラーに直面した際、難解な英語エラーメッセージや解決の糸口が掴めず、挫折しやすい課題を抱えている。

1.2 目的

白紙からコードを一から書き上げる実践的な学習習慣を定着させ、自律的にエラーを解決できる力を養う。ローカルAIによる初学者向けの段階的ヒント提示、実行結果の差分解説、組み込み関数辞書、成長記録の蓄積により、挫折せず楽しく継続できるプログラミング学習環境を提供する。

1.3 想定利用者（ターゲット層）

  • 主要ターゲット： 小学校高学年〜中高生、大学・専門学校の未経験生、社会人初学者
  • 利用シーン： 教育機関・学校のPC教室（ローカル環境）、自宅PCでの自習

2. システム化方針・スコープ

2.1 言語スコープ

  • 実行・採点対象言語： Python（Windows用 Embeddable Package をアプリに同梱し、利用者の環境構築を不要とする）
  • 比較表示対象言語： Java、JavaScript（構文や書き方の対比・辞書参照のみ提供し、初期版では実行環境は提供しない）

2.2 AI・データ処理方針

  • ローカル推論完結： AI分析・ヒント生成はユーザー端末内（ローカル）で処理し、通信費の抑制およびオフライン学習を可能とする。
  • データ保存のハイブリッド分離：
    • 端末内保存： ユーザーが入力したコード全文、一時編集内容、個人設定（プライバシー保護と即時オートセーブ）
    • クラウド同期： ログイン時の学習履歴（合否、得点、エラー種別、達成日時、バッジ獲得状況） ※コード本文は原則クラウドに送信しない

3. 機能要件一覧 (FR: Functional Requirements)

要件ID 要件名 詳細要件・仕様 区分
FR-01 自由創作モード 白紙のエディタでPythonコードを自由に記述・実行し、標準出力・標準エラーを即座に確認できること。 必須
FR-02 課題演習モード 課題文、目標、期待出力を表示し、白紙からコードを作成してテストを実行できること。 必須
FR-03 自動採点機能 100点満点（要件達成度50点 / 実行結果30点 / コード妥当性20点）で採点し、80点以上かつ無エラーで合格判定を行うこと。 必須
FR-04 段階的AIヒント エラーに対し、答えを直接出さず「着眼点」「考え方」「修正コード例（希望時）」の3段階で支援を提供すること。 必須
FR-05 ローカルAI推論基盤 端末内の軽量LLMで推論を行い、外部APIなしで動作すること。モデル未導入時でもPython実行を停止しないこと。 必須
FR-06 コード自動保存 入力中のコードを数秒間隔で端末内に自動一時保存し、再起動時に直前の状態を復元できること。 必須
FR-07 学習履歴クラウド同期 課題結果、得点、エラー種別、解決状況、実績をクラウドDBと同期できること（コード本文は非送信）。 必須
FR-08 ゲスト・ログイン切替 ゲスト状態（ローカル保存のみ）とログイン状態（クラウド同期）に対応し、ログイン時に端末内ログをマージできること。 必須
FR-09 構文・関数辞書 基本構文や関数（print, len, if, for等）の使い方を検索・閲覧できること。 必須
FR-10 既習言語構文比較 Pythonの構文とJava/JavaScriptの書き方を左右に対比表示できること（静的データ表示）。 必須
FR-11 コーディング補助 ワンクリックでのコード自動整形（インデント等）および基本構文スニペットの挿入ができること。 必須
FR-12 やさしさ表示切替 UI表記を「子ども向け（ルビあり）」と「大人向け（標準表記）」で切り替えられること。 必須
FR-13 アチーブメント機能 課題達成や学習継続、エラー解決に応じてバッジを付与し、一覧表示できること。 必須

4. 非機能要件 (NFR: Non-Functional Requirements)

4.1 性能・パフォーマンス

  • 実行応答： 通常のコード実行は、実行ボタン押下から1秒以内に標準出力・エラーを表示すること。
  • AI応答： CPU環境でのローカルAI推論は5〜10秒以内を目標とし、処理中はローディング表示を行うこと。
  • 起動時間： アプリ起動から3秒以内にメイン画面を表示すること。

4.2 安全性・セキュリティ

  • 実行時間制限： コード実行時間は最大5秒とし、超過時は子プロセスを含め強制終了（タイムアウト）すること。
  • 出力サイズ制限： 出力バッファの上限は合計1MiBとし、無限出力によるメモリ枯渇を防止すること。
  • データ保護： ユーザーのコード本文全文はクラウドDBへ送信せず、メタデータとハッシュ値のみを送信すること。

4.3 信頼性・可用性（フォールバック）

  • オフライン動作保証： ネットワーク未接続時でも、Pythonコードの編集・実行・辞書参照・ローカル保存を継続できること。
  • AI障害時の縮退運転： AIモデルのダウンロード中や推論失敗時でも、Python実行や機械的テストを停止せず学習を継続できること。

4.4 ユーザビリティ

  • 初学者・小中学生が直感的に操作できるよう、専門用語を避けた親しみやすい日本語を採用すること。
  • 画面解像度 1366×768 以上で各パネル（エディタ、コンソール、AI、辞書）が快適にリサイズ・操作できること。
