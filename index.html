プログラミング初学者向け AI誤り分析アシスタント 仕様書（仮案）

アーキテクチャ: Tauri v2 (Desktop App) 対象OS: Windows 10/11 チーム規模: 6名

1. アプリ概要・目的

プログラミング初学者がコードを実行した際に発生したエラー文やソースコードを解析し、答えを直接教えるのではなく「原因とヒント」段階的に提示するデスクトップアプリケーション。

  • ターゲット層: 大学・専門学校のプログラミング初学者（Python / Rust / C / JS 等）
  • コア体験: 「どこで詰まっているか」を即座にAIが察知し、気づきを与える教育的サポート

2. 技術スタック & 役割分担概要

区分 使用技術 主な役割
フロントエンド TypeScript, React, Tailwind CSS UIデザイン、入力フォーム、チャット/ヒント表示、エディタ制御
エディタUI Monaco Editor (VS Code互換) コードのシンタックスハイライト、行番号表示、エラー箇所の波線表示
バックエンド Rust (Tauri v2) ローカルファイル操作、APIキー安全管理、外部AIサービス(OpenAI/Claude)との通信
通信・データ交換 Tauri Command (IPC通信, JSON) フロント（TypeScript）とバックエンド（Rust）間のデータ結合

4. コードエディタ機能 画面上でコードを直接記述・貼り付けできるエディタ（Monaco Editor） フロント

4. フロント ⇄ Rust バックエンド間 データ仕様 (IPC)

フロントとバックエンドを別々で開発し、最後に繋ぐためのデータインターフェースです。

AI解析リクエスト (TypeScript → Rust)

// Tauri Command: invoke('analyze_code_error', { payload })
{
  "language": "python",
  "code": "def add(a, b):\n    return a + b",
  "errorMessage": "TypeError: unsupported operand type(s) for +: 'int' and 'str'",
  "hintLevel": 1 // 1: 概要ヒント, 2: 原因箇所, 3: 修正例の方向性
}

AI解析レスポンス (Rust → TypeScript)

{
  "status": "success",
  "hintTitle": "型（データ種別）の不一致が原因です",
  "hintContent": "数値（int）と文字列（str）を直接足し合わせようとしています。変数の中身が意図した型になっているか確認しましょう。",
  "targetLine": 2
}

5. チーム開発・提出時の前提ルール

  • ローカル完結: 外部サーバーは準備せず、インストーラー（`.exe`）をビルドして提出可能にする。
  • Git管理: `.env`（APIキー格納用）は絶対リポジトリに含めず、`.gitignore` で除外する。
  • バージョン固定: `rust-toolchain.toml` と `package.json` でRustおよびNode.jsのバージョンを統一する。
