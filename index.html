プログラミング学習 AI誤り分析アシスタント 総合仕様書

改訂日時：2026年10月 アーキテクチャ：Tauri v2 画面：React / TypeScript バックエンド：Rust 対象：Windows 10 / 11 開発チーム：6名

本書は、自由創作におけるマルチファイル管理・相互実行・エラー追跡ジャンプを含む全設計を統合した改訂版総合仕様書です[cite: 3]。

1. アプリ概要・目的

小学生高学年から大人までのプログラミング初学者が、コードを自分で書き、実行結果やエラーを確認しながら学習できるデスクトップアプリケーションを提供する[cite: 3]。学習モードは「自由創作」と「課題演習」の2種類とし、ローカルAIによるエラー分析・段階的ヒント、課題テストによる採点、辞書・他言語構文比較、マルチファイル管理、学習記録の同期を備える[cite: 3]。

  • 初期対応言語：Python（実行対象）。Java / JavaScript は構文比較・説明の対象とし、初期版では実行環境を提供しない[cite: 3]。
  • 保存方針：編集コードおよび自由創作プロジェクトは端末内、学習記録はログイン時にクラウドへ保存・同期する[cite: 3]。
  • AI方針：原則ローカルAIを利用する。AIが利用できなくても、編集・実行・テスト・保存を継続できる[cite: 3]。
  • 合格基準：採点が完了し、合計80点以上、かつ構文エラー・実行時エラー・タイムアウトがないこと[cite: 3]。

構成要素 責務 技術・方針

Python実行環境 ユーザーコード、課題テスト、モジュール間相互実行（import）を実行する[cite: 3]。 配布物に同梱したPythonランタイム（Windows Embeddable Package）[cite: 3]。

4. 課題採点仕様

4.1 配点

評価項目 配点 評価方法
要件達成度[cite: 3] 50点[cite: 3] 課題の要求事項を満たしているかを評価する[cite: 3]。
実行結果[cite: 3] 30点[cite: 3] 自動テストケースの成功数・重要度に応じて算出する[cite: 3]。
コード妥当性[cite: 2, 3] 20点[cite: 3] 読みやすさ、適切な構造、課題に対する妥当性を評価する[cite: 3]。
合計[cite: 3] 100点[cite: 3] 各項目の点数を合算する（80点以上かつエラーなしで合格）[cite: 3]。

4.2 段階的ヒント仕様

  1. 第1段階（着眼点）：どの条件・処理を見直すべきかを示す[cite: 3]。
  2. 第2段階（考え方）：関連する構文やロジックの考え方を説明する[cite: 3]。
  3. 第3段階（修正例）：必要な場合に限り、短いコード修正例を示す[cite: 3]。

5. マルチファイル・ワークスペース詳細仕様

5.1 作業ディレクトリ（CWD）と実行方式

  • 自由創作モード時、ユーザーのプロジェクトフォルダパス（例: %APPDATA%/CodeLab/projects/my_project/）を作業ディレクトリ（Current Working Directory）として設定してPythonを実行する。
  • これにより、同一フォルダ内のファイルを import helper や from utils import calc として直接読み込み可能とする。

5.2 トレースバック解析（Traceback Parser）とエラージャンプ

  • Pythonの標準エラー出力をパースし、正規表現 File "([^"]+)", line (\d+) でエラー発生元のファイル名と行番号を抽出する。
  • 現在アクティブなファイル以外のファイルでエラーが発生している場合、コンソールに「👉 該当ファイル・行を開いて修正する」アクションリンクを表示する。
  • リンク押下時、フロントエンドは該当ファイルのタブを開き、Monaco Editorのカーソルを該当行に移動させてエラー波線・ハイライト表示を行う。

5.3 AIエラー解析のファイル間連携

  • 呼び出し先ファイルでエラーが発生した場合、実行エントリーファイルとエラー元ファイルの両方のコードをプロンプトに含めてAIに解析させる。
  • AIは「呼び出し側のファイルではなく、呼び出された側の関数の定義に原因がある」旨を初学者向けに明確に解説する。

7. 受け入れ基準（テスト可能な完了条件）

ID 対象 受け入れ条件
AC-01 Python実行 正常なコードの出力を表示し、構文エラー・実行時エラーを区別して表示できる[cite: 3]。
AC-02 停止・タイムアウト 無限ループ等のテストコードを5秒後に停止でき、関連プロセスが残らず、UIが操作可能に戻る[cite: 3]。
AC-03 出力制限 大量出力時に合計1MiBで打ち切り、アプリが応答不能にならない[cite: 3]。
AC-04 採点 テストの成功・失敗と部分点が一致し、配点合計は100点、80点以上合格が適用される[cite: 3]。
AC-05 AI失敗 AIモデル未導入・オフライン・読み込み失敗でも、編集・実行・テスト・ローカル保存を継続できる[cite: 3]。
AC-06 ローカル保存 編集後に自動保存され、アプリ再起動後に直前の内容を復元できる[cite: 3]。
AC-07 クラウド同期 オフライン中の学習記録を接続回復後に再送し、重複登録せず、失敗状態をユーザーに表示する[cite: 3]。
AC-08 ゲスト移行 ログイン時にゲスト記録を統合でき、既存記録の重複や意図しない消失がない[cite: 3]。
AC-09 構文比較 Pythonと選択言語のレビュー済み比較例を表示し、比較対象言語のコードを実行しない[cite: 3]。
AC-10 実行隔離 設計した権限制限・ネットワーク制限・ファイルアクセス制限が機能する[cite: 3]。
AC-11 マルチファイル実行 同一プロジェクトフォルダ内の別ファイルを import して関数呼び出し・値取得が正常に行えること。
AC-12 エラージャンプ ＆ 修正 呼び出し先ファイルでエラーが発生した際、コンソール上にエラー発生ファイル名・行番号が表示され、クリックで該当ファイルの該当行へ切り替わって表示・修正できること。
