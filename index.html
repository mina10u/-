プログラミング学習 AI誤り分析アシスタント 仕様書

最終更新日時: 2026年10月9日 10:26 アーキテクチャ: Tauri v2 (Desktop App) 対象OS: Windows 10/11 チーム規模: 6名

1. アプリ概要・目的

小学生高学年から大人までのプログラミング初心者が、コード実行時のエラーや疑問を直感的に解消できるデスクトップアプリケーション。答えを直接教えるのではなく「原因・ひらがな解説・関連する辞書・モチベーション向上要素」を提示します。

  • ターゲット層: 小学生高学年、中高生、大学・専門学校生、社会人のプログラミング初学者
  • コア体験: 「やさしい言葉でのエラー解説」「ふりがな表示対応の関数辞書」「アチーブメント獲得で楽しく学べる問題演習」の統合学習体験

2. 機能一覧

2.1 コア学習・開発機能

機能名 機能概要 担当領域
1. コードエディタ機能 文字サイズ変更・色分け表示（Monaco Editor）に対応した読みやすいエディタ。 フロント
2. やさしい出力コンソール 実行結果（print等）を表示。英語エラーを自動で「わかりやすい日本語」に翻訳表示。 フロント / Rust
3. ふりがな付き関数・構文辞書 基本関数（`print`, `len` 等）の解説。難解な漢字や専門用語にふりがな（ルビ）を表示可能。 フロント / Rust
4. 辞書便利機能（履歴/頻出/お気に入り） 「検索履歴」「よく調べるワード」「単語のお気に入り登録（ブックマーク）」機能。 フロント / Rust
5. スキルチェック・問題演習 「入門・初級・中級」の段階的テスト問題と自動採点機能。 フロント / Rust
6. アチーブメント（実績・バッジ）獲得機能 NEW 課題達成・学習継続・辞書利用等に応じてバッジや称号を獲得できる学習モチベーション維持機能。 フロント / Rust

2.2 AI支援・アクセシビリティ機能

機能名 機能概要 担当領域
7. やさしさ切り替え（モード設定） 「こども（ふりがなあり・やさしい言葉）」/「大人（標準表記）」のUI表現切り替えスイッチ。 フロント
8. 段階的AIヒント生成 設定されたモード（年齢層）に合わせてAIがヒントの言葉遣いや難易度を自動調整。 Rust (AI)
9. ヒント ⇄ 辞書 連動機能 AIヒント内の関連キーワードから直接ワンタップで関数辞書へ移動できる機能。 共通 (IPC)
10. 対話型お助けチャット 「ここがよくわからない」と気軽に話しかけて質問できるチャット機能。 フロント / Rust
