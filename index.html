1. アプリ概要・目的

小学生高学年から大人までのプログラミング初心者が、自分で一からコードを書きながらエラーや疑問を直感的に解消できるデスクトップアプリケーション。「答えのない自由創作」と「一から書く課題演習」の2つの学習モードを提供し、AIが親身にサポートします。

  • ターゲット層: 小学生高学年、中高生、大学・専門学校生、社会人のプログラミング初学者
  • コア体験: 「自由記述・サンドボックス」「一から書く課題演習」「やさしいエラー解説」「ふりがな付き関数辞書」「アチーブメント獲得」の統合学習体験

2. 機能一覧

2.1 コア学習・開発機能

機能名 機能概要 担当領域
1. フリープレイ・サンドボックスモード NEW お題や正解がない完全自由な環境。自分のアイデアを自由に記述・実行・ファイル保存できる機能。 フロント / Rust
2. 一から書く課題演習モード お題（仕様）を元に白紙からコードを作成し、実行結果を自動採点・チェックする機能。 フロント / Rust
3. やさしい出力コンソール 実行結果（print等）を表示。英語エラーを自動で「わかりやすい日本語」に翻訳表示。 フロント / Rust
4. ふりがな付き関数・構文辞書 基本関数（`print`, `len` 等）の解説。難解な漢字や専門用語にふりがな（ルビ）を表示可能。 フロント / Rust
5. 辞書便利機能（履歴/頻出/お気に入り） 「検索履歴」「よく調べるワード」「単語のお気に入り登録（ブックマーク）」機能。 フロント / Rust
6. アチーブメント（実績・バッジ）獲得機能 課題達成・自由創作での成果・学習継続に応じてバッジや称号を獲得できる機能。 フロント / Rust

2.2 AI支援・アクセシビリティ機能

機能名 機能概要 担当領域
7. やさしさ切り替え（モード設定） 「こども（ふりがなあり・やさしい言葉）」/「大人（標準表記）」のUI表現切り替えスイッチ。 フロント

3. フロント ⇄ Rust バックエンド間 データ仕様 (IPC)

{
  "currentMode": "sandbox", // "sandbox" (自由創作) / "challenge" (課題演習)

    "fileName": "my_first_script.py",
    "code": "print('自由にコードを書いてみよう！')"
  }
}

4. 画面レイアウト構成案

  • ヘッダー: メインモード切替（「サンドボックス（自由創作）」/「課題演習」） ＆ やさしさ（こども/大人）切り替え
  • 左エリア: フリーエディタ ＆ やさしい出力コンソール（実行結果 / エラー）
  • 右上エリア: AIヒント・対話チャット（モードに応じてAIの会話スタイルが自動変化）
  • 右下エリア: 関数・構文辞書（ルビ表示対応、タブ切り替え機能付き）
