1. アプリ概要・方針

本仕様書は、デスクトップアプリ（Tauri v2）として構築するプログラミング学習アシスタントの初期リリース版（v1.0）の要件を定義するものです。最初はPythonに特化して完成度を高め[cite: 2]、その後の拡張（複数言語対応等）に備えた堅実なアーキテクチャを採用します。

  • 対象環境: Windows 10/11向けデスクトップアプリ（Tauri v2, React/TypeScript, Rust）[cite: 2]
  • コア方針: Pythonの編集・実行・採点・ローカルAI分析を一通り完成させた上で、ゲスト・ログイン・クラウド同期機能を統合する[cite: 2]。

4. 課題の採点ルールと例外処理

採点配点 (合計100点満点・80点以上合格)[cite: 2]

採点項目 配点[cite: 2] 判定方法[cite: 2]
要件達成度 50点[cite: 2] 課題で指定された処理を満たしているか[cite: 2]。
実行結果 30点[cite: 2] テスト入力に対する出力が期待値と合うか[cite: 2]。
コードの妥当性 20点[cite: 2] ローカルAIが処理内容やコードの適切さを評価[cite: 2]（模範解答と異なっていても正しければ評価）。

例外ルール

  • 構文エラーや実行時エラーがある場合は、通常の合格判定をしない[cite: 2]。
  • 必須のテストに失敗した場合は、その結果を点数とフィードバックに反映する[cite: 2]。
  • AIの応答に失敗した場合は、採点不能として再試行できるようにし、仮の点数を合格点として確定しない[cite: 2]。
  • アプリ側の実行障害と、学習者が書いたコードのエラーを明確に区別する[cite: 2]。

6. 開発の順番と6名チーム分担案

段階的実装のステップ

  1. 土台を作る (最優先): Tauri v2の起動、React画面、Rustとの連携[cite: 2]。
  2. Pythonエディタと実行: コード入力、実行ボタン、標準出力、エラー表示、タイムアウト制御[cite: 2]。
  3. 課題演習と自動採点: テストケース、期待値比較、機械的採点からAI評価への拡張[cite: 2]。
  4. ローカルAI接続: エラー解説、論理エラーヒント、チャット、課題評価の統合[cite: 2]。
  5. 保存・学習履歴・ゲスト機能: 端末内保存、成長カルテ、アチーブメント、クラウド同期[cite: 2]。
  6. 学習支援と配布準備: 辞書、ふりがな、コード整形、インストーラー仕上げ[cite: 2]。

6名チームの担当分け
