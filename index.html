プログラミング初学者向け AI誤り分析アシスタント 仕様書

アーキテクチャ: Tauri v2 (Desktop App) 対象OS: Windows 10/11 チーム規模: 6名

1. アプリ概要・目的

プログラミング初学者がコードを実行した際に発生したエラー文やソースコードを解析し、答えを直接教えるのではなく「原因・ヒント・関連する関数辞書」を段階的に提示するデスクトップアプリケーション。

  • ターゲット層: 大学・専門学校のプログラミング初学者
  • コア体験: 「出力結果の確認」「エラー原因の気づき」「関数辞書での学び」を1つの画面で完結させるサポート体験

2. 機能一覧

2.1 コア学習・開発機能

機能名 機能概要 担当領域
1. コードエディタ機能 コード記述・編集領域（Monaco Editor）。構文強調表示や行番号表示に対応。 フロント
2. 出力コンソール表示 NEW コード実行時の標準出力（print等）やエラーメッセージを表示するコンソールエリア。 フロント / Rust
3. 組み込み関数・構文辞書 NEW よく使われる基本関数（`print`, `len`, `input` 等）や構文の解説・コード例を検索・閲覧できる辞書パネル。 フロント / Rust

2.2 AI支援・ガイド機能

機能名 機能概要 担当領域
4. 段階的AIヒント生成 「レベル1: エラーの概要」「レベル2: 原因箇所」「レベル3: 考え方」を段階的に生成。 Rust (AI)
5. ヒント ⇄ 辞書 連動機能 NEW AIが生成したヒント内に、関連する関数辞書（例: `len()`）への直接リンクを表示しクリックで辞書を開く機能。 共通 (IPC)
6. 対話型お助けチャット ヒントに対して「ここがよくわからない」と追加質問できる対話インターフェース。 フロント / Rust

3. フロント ⇄ Rust バックエンド間 データ仕様 (IPC)

AI解析レスポンス（辞書連動データ含む）

{
  "status": "success",
  "hintTitle": "文字列と数値の結合エラーです",
  "hintContent": "print文の中で数値と文字列を直接『+』で繋ごうとしています。数値を str() 関数で変換するか、カンマ区切りを使いましょう。",
  "targetLine": 3,
  "relatedDictionaryKeys": ["print", "str"]  // AIが自動抽出した関連する関数辞書のキーワード
}

関数辞書データ構造案（JSON）

{
  "key": "print",
  "title": "print() 関数",
  "category": "組み込み関数",
  "description": "画面に文字や数値を出力するための関数です。",
  "example": "print('Hello World')\nprint('結果:', 10)",
  "tips": "カンマ (,) で区切ると、複数の値を並べて出力できます。"
}

4. 画面レイアウト構成案（3分割パネル）

  • 左エリア: コードエディタ ＆ 下部出力コンソール（実行結果 / print出力）
  • 右上エリア: AIヒント ＆ 対話チャット画面
  • 右下エリア: 関数・構文辞書パネル（AIヒントからのリンク移動対応）
