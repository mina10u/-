1. アプリ概要・目的

小学生高学年から大人までのプログラミング初心者が、自分で一からコードを書きながらエラーや疑問を直感的に解消できるデスクトップアプリケーション。「自由創作」と「一から書く課題演習」の2モードを用意し、ローカルAIによるエラー・論理分析、クラウドによる学習履歴同期で楽しく学習をサポートします。

  • ターゲット層: 小学生高学年、中高生、大学・専門学校生、社会人のプログラミング初学者[cite: 2]
  • コア体験: 複数言語対応（Python/JavaScript）、ローカルAIによるやさしいエラー・差分解説、クラウド同期型の成長カルテ、AIによる課題採点、アチーブメント獲得の統合学習体験

3. 機能一覧

3.1 コア学習・開発補助機能

機能名 機能概要 担当領域
1. フリープレイ・サンドボックスモード お題や正解がない完全自由な環境。対応言語（Python/JS等）を選択して自由に記述・実行・保存。 フロント / Rust
2. 一から書く課題演習モード お題（仕様）を元に白紙からコードを作成し、機械的検証とAI評価を組み合わせた自動採点を受けられる機能。 フロント / ローカルAI
3. コード整形 ＆ スニペット挿入 言語ごとのフォーマッタによる自動インデント整列、および基本構文の型挿入ボタン[cite: 2]。 フロント[cite: 2]
4. やさしい出力コンソール ＆ 差分解説 実行結果を表示。文法エラーの日本語翻訳に加え、期待結果と異なる場合の差分（Diff）ヒント表示[cite: 2]。 フロント / ローカルAI
5. ふりがな付き関数・構文辞書 選択言語に応じた関数解説。難解な漢字や専門用語にふりがな（ルビ）を表示可能（履歴・お気に入り対応）[cite: 2]。 フロント[cite: 2]

5. 追加詳細仕様（AI・クラウド・複数言語・採点）

① 複数プログラミング言語への対応

  • 初期対応言語: Python、JavaScript の2言語。
  • 言語選択: エディタ画面上部で言語を切替可能。切替時はコード保持または初期化を選択。
  • 実行・整形・辞書: 選択された言語に応じたランタイム実行、フォーマッタ、専用の関数辞書データを動的に連動。

② ローカルAI仕様

  • 実行場所: ユーザーのPC内（外部APIに依存しないため、オフラインでもエラー解説やチャットが利用可能）。
  • 入力・出力: コード、実行結果、エラー情報、課題文を入力し、初心者向け解説・問題箇所・改善ヒントを出力[cite: 2]。

③ クラウド保存・学習履歴の同期ルール

  • 保存データ: ユーザーID、エラー履歴（発生日時、種類、解決状態）、修正ログ（コード変遷）、学習進捗（課題達成状況）、アチーブメント、辞書お気に入り[cite: 2]。
  • 同期フロー: ログイン後にサーバーから最新データを取得 ➔ 記録作成時に自動送信 ➔ 失敗時は未同期として保持しオフライン再送。

④ AIによる課題採点の仕様

  • 検証の組み合わせ: 機械的検証（タイムアウト、出力条件の合致確認）と、ローカルAIによる「処理の妥当性・意図の評価」を組み合わせたハイブリッド判定。
  • 採点基準案: 要件達成度（50点）＋ 実行結果・期待値一致（30点）＋ コード妥当性（20点）＝ 合計100点（模範解答と異なっていても正しく動作すれば合格とする寛容な設計）。
