プログラミング初学者向け AI誤り分析アシスタント 仕様書

最終更新日: 2026年10月9日 アーキテクチャ: Tauri v2 (Desktop App) 対象OS: Windows 10/11 チーム規模: 6名

1. アプリ概要・目的

プログラミング初学者がコードを実行した際に発生したエラー文やソースコードを解析し、答えを直接教えるのではなく「原因・ヒント・関連する関数辞書」を段階的に提示するデスクトップアプリケーション。

  • ターゲット層: 大学・専門学校のプログラミング初学者
  • コア体験: 「自由記述でのエラー解析」「組み込み関数辞書での学び」「スキルチェック問題演習」を1つの環境でシームレスに提供する統合学習システム

2. 機能一覧

2.1 コア学習・開発機能

機能名 機能概要 担当領域
1. コードエディタ機能 コード記述・編集領域（Monaco Editor）。構文強調表示や行番号表示に対応。 フロント
2. 出力コンソール表示 コード実行時の標準出力（print等）やエラーメッセージを表示するコンソールエリア。 フロント / Rust
3. 組み込み関数・構文辞書 よく使われる基本関数（`print`, `len`, `input` 等）や構文の解説・コード例を検索・閲覧できる辞書パネル。 フロント / Rust
4. スキルチェック・問題演習機能 NEW 難易度別の課題（例: 変数・IF文・For文）を出題し、プログラムの実行結果を自動採点してレベル測定する機能。 フロント / Rust

2.2 AI支援・ガイド機能

機能名 機能概要 担当領域
5. 段階的AIヒント生成 「レベル1: エラーの概要」「レベル2: 原因箇所」「レベル3: 考え方」を段階的に生成。問題演習時にもヒントを提供。 Rust (AI)
6. ヒント ⇄ 辞書 連動機能 AIが生成したヒント内に、関連する関数辞書（例: `len()`）への直接リンクを表示しクリックで辞書を開く機能。 共通 (IPC)
7. 対話型お助けチャット ヒントや問題の解き方に対して「ここがよくわからない」と追加質問できる対話インターフェース。 フロント / Rust

3. フロント ⇄ Rust バックエンド間 データ仕様 (IPC)

問題データの構造案（JSON）

{

  "title": "偶数・奇数の判定プログラムを作ろう",
  "difficulty": "初級", // 入門 / 初級 / 中級

4. 画面レイアウト構成案（モード切り替え対応）

  • フリー記述モード: 左側にコードエディタ＆出力コンソール、右側にAIヒント＆関数辞書。
  • 問題演習モード: 左上に問題文＆テストケース、左下にコードエディタ、右側にAIヒント＆関数辞書。
