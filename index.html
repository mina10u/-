1. アプリ概要・目的

小学生高学年から大人までのプログラミング初心者が、自分で一からコードを書きながらエラーや疑問を直感的に解消できるデスクトップアプリケーション。「自由創作」と「一から書く課題演習」の2モードを用意し、コーディング支援ツールや成長カルテで楽しく学習をサポートします。

  • ターゲット層: 小学生高学年、中高生、大学・専門学校生、社会人のプログラミング初学者
  • コア体験: 「自由記述・サンドボックス」「一から書く課題演習」「やさしいエラー解説」「エラー履歴・成長カルテ」「ふりがな付き関数辞書」「アチーブメント獲得」の統合学習体験

2. 機能一覧

2.1 コア学習・開発補助機能

機能名 機能概要 担当領域
1. フリープレイ・サンドボックスモード お題や正解がない完全自由な環境。自分のアイデアを自由に記述・実行・ファイル保存できる機能。 フロント / Rust
2. 一から書く課題演習モード お題（仕様）を元に白紙からコードを作成し、実行結果を自動採点・チェックする機能。 フロント / Rust
3. コード整形 ＆ スニペット挿入 ワンタップでインデント等を自動整列するフォーマッタ機能、および基本構文（if/for等）の型挿入ボタン。 フロント
4. やさしい出力コンソール 実行結果（print等）を表示。英語エラーを自動で「わかりやすい日本語」に翻訳表示。 フロント / Rust
5. ふりがな付き関数・構文辞書 基本関数（`print`, `len` 等）の解説。難解な漢字や専門用語にふりがな（ルビ）を表示可能。 フロント / Rust
6. 辞書便利機能（履歴/頻出/お気に入り） 「検索履歴」「よく調べるワード」「単語のお気に入り登録（ブックマーク）」機能。 フロント / Rust

2.2 AI支援・成長記録・モチベーション機能

機能名 機能概要 担当領域
7. エラー履歴・成長カルテ 過去に発生したエラー、AIの解決ヒント、自分の修正ログを蓄積し、いつでも振り返れる成長カルテ機能。 フロント / Rust
8. アチーブメント（実績・バッジ）獲得機能 課題達成・自由創作での成果・学習継続・エラー解決に応じてバッジや称号を獲得できる機能。 フロント / Rust
9. やさしさ切り替え（モード設定） 「こども（ふりがなあり・やさしい言葉）」/「大人（標準表記）」のUI表現切り替えスイッチ。 フロント
10. モード別AIサポート ＆ チャット 【自由創作】相談応答 / 【課題演習】組み立てヒント提示。対話形式で質問も可能。 Rust (AI)

  { "label": "for文（繰り返し）", "snippet": "for i in range(5):\n    # ここに処理を書く\n" }
]

4. 画面レイアウト構成案

  • ヘッダー: モード切替（「自由創作」/「課題演習」） ＆ やさしさ切替 ＆ 「成長カルテ」「アチーブメント」アイコン
  • 左エリア: フリーエディタ（「コード整形」「スニペット挿入」ボタン付き） ＆ やさしい出力コンソール
  • 右上エリア: AIヒント・対話チャット（モードに応じてAIの対応が変化）
  • 右下エリア: 関数・構文辞書（ルビ表示対応、タブ切り替え機能付き）
