プログラミング学習 AI誤り分析アシスタント 仕様書

最終更新日時: 2026年10月9日 10:20 アーキテクチャ: Tauri v2 (Desktop App) 対象OS: Windows 10/11 チーム規模: 6名

1. アプリ概要・目的

小学生高学年から大人までのプログラミング初心者が、コード実行時のエラーや疑問を直感的に解消できるデスクトップアプリケーション。答えを直接教えるのではなく「原因・ひらがな解説・関連する辞書」を親しみやすく提示します。

  • ターゲット層: 小学生高学年、中高生、大学・専門学校生、社会人のプログラミング初学者
  • コア体験: 「やさしい言葉でのエラー解説」「ふりがな表示対応の関数辞書」「楽しみながらレベルアップできる問題演習」の統合学習体験

2. 機能一覧

2.1 コア学習・開発機能

機能名 機能概要 担当領域
1. コードエディタ機能 文字サイズ変更・色分け表示（Monaco Editor）に対応した読みやすいエディタ。 フロント
2. やさしい出力コンソール 実行結果（print等）を表示。英語エラーを自動で「わかりやすい日本語」に翻訳表示。 フロント / Rust
3. ふりがな付き関数・構文辞書 NEW 基本関数（`print`, `len` 等）の解説。難解な漢字や専門用語にふりがな（ルビ）を表示可能。 フロント / Rust
4. 辞書便利機能（履歴/頻出/お気に入り） 「検索履歴」「よく調べるワード」「単語のお気に入り登録（ブックマーク）」機能。 フロント / Rust
5. スキルチェック・問題演習 NEW 「小学生・入門モード（選択肢/穴埋め）」から「中級モード（自由記述）」まで対応した問題演習。 フロント / Rust

2.2 AI支援・アクセシビリティ機能

機能名 機能概要 担当領域
6. やさしさ切り替え（モード設定） NEW 「こども（ふりがなあり・やさしい言葉）」/「大人（標準表記）」のUI表現切り替えスイッチ。 フロント
7. 段階的AIヒント生成 設定されたモード（年齢層）に合わせてAIがヒントの言葉遣いや難易度を自動調整。 Rust (AI)

3. フロント ⇄ Rust バックエンド間 データ仕様 (IPC)

年齢層（モード）対応AIリクエスト構造

{
  "language": "python",
  "code": "print('こんにちは' + 10)",
  "errorMessage": "TypeError: can only concatenate str (not 'int') to str",
  "userMode": "junior", // "junior" (小学生高学年〜中学生向け) / "standard" (一般・大学生向け)
  "hintLevel": 1
}

辞書データ構造（ふりがな・難易度フラグ対応）

{
  "key": "print",
  "title": "print() 関数",
  "titleRuby": "プリント かんすう",  // 小学生向けふりがな
  "category": "組み込み関数",
  "description": "画面（がめん）に文字や数値を表示（ひょうじ）するための基本コマンドです。",
  "example": "print('Hello World')\nprint('けっか:', 10)",
  "isBookmarked": false,
  "searchCount": 5
}

4. 画面レイアウト構成案（3分割＋モード切替）

  • ヘッダー: モード切り替え（「こどもモード / ふりがな表示」スイッチ）
  • 左エリア: コードエディタ ＆ やさしい出力コンソール
  • 右上エリア: AIヒント ＆ やさしいチャット画面
  • 右下エリア: 関数・構文辞書（ルビ表示対応、タブ切り替え機能付き）
