プログラミング初学者向け AI誤り分析アシスタント 仕様書

最終更新日時: 2026年10月9日 10:15 アーキテクチャ: Tauri v2 (Desktop App) 対象OS: Windows 10/11 チーム規模: 6名

1. アプリ概要・目的

プログラミング初学者がコードを実行した際に発生したエラー文やソースコードを解析し、答えを直接教えるのではなく「原因・ヒント・関連する関数辞書」を段階的に提示するデスクトップアプリケーション。

  • ターゲット層: 大学・専門学校のプログラミング初学者
  • コア体験: 「自由記述でのエラー解析」「辞書（検索履歴・お気に入り機能付き）での学習」「スキルチェック問題演習」を1つの環境で提供する統合学習システム

2. 機能一覧

2.1 コア学習・開発機能

機能名 機能概要 担当領域
1. コードエディタ機能 コード記述・編集領域（Monaco Editor）。構文強調表示や行番号表示に対応。 フロント
2. 出力コンソール表示 コード実行時の標準出力（print等）やエラーメッセージを表示するコンソールエリア。 フロント / Rust
3. 組み込み関数・構文辞書 よく使われる基本関数（`print`, `len`, `input` 等）や構文の解説・コード例を検索・閲覧できる辞書パネル。 フロント / Rust
4. 辞書便利機能（履歴/頻出/お気に入り） 「検索履歴」「よく調べるワード（アクセス順）」「単語のお気に入り登録（ブックマーク）」機能。 フロント / Rust
5. スキルチェック・問題演習機能 難易度別の課題を出題し、プログラムの実行結果を自動採点してレベル測定する機能。 フロント / Rust

2.2 AI支援・ガイド機能

機能名 機能概要 担当領域
6. 段階的AIヒント生成 「レベル1: エラーの概要」「レベル2: 原因箇所」「レベル3: 考え方」を段階的に生成。 Rust (AI)
7. ヒント ⇄ 辞書 連動機能 AIが生成したヒント内に、関連する関数辞書（例: `len()`）への直接リンクを表示しクリックで辞書を開く機能。 共通 (IPC)
8. 対話型お助けチャット ヒントや問題の解き方に対して「ここがよくわからない」と追加質問できる対話インターフェース。 フロント / Rust

3. フロント ⇄ Rust バックエンド間 データ仕様 (IPC)

拡張された辞書データ構造案（JSON）

{
  "key": "print",
  "title": "print() 関数",
  "category": "組み込み関数",
  "description": "画面に文字や数値を出力するための関数です。",
  "example": "print('Hello World')\nprint('結果:', 10)",
  "tips": "カンマ (,) で区切ると、複数の値を並べて出力できます。",
  "isBookmarked": true,  // お気に入り登録フラグ
  "searchCount": 12      // 検索・閲覧回数（よく調べるワード用）
}

検索履歴・お気に入りリスト共有構造

{
  "searchHistory": ["print", "if", "type_error"], // 最近検索した単語（上限10件）
  "favoriteKeys": ["print", "len", "for"]         // お気に入り登録された単語キー一覧
}

4. 画面レイアウト構成案（3分割＋辞書タブ）

  • 左エリア: コードエディタ ＆ 下部出力コンソール
  • 右上エリア: AIヒント ＆ 対話チャット画面
  • 右下エリア: 関数・構文辞書（「検索」「履歴」「お気に入り」「頻出」のタブ切り替え対応）
